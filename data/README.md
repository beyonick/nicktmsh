# Данные сайта

Два файла. Весь текст, который человек читает на сайте, кроме
статичных секций главной, лежит здесь. Вёрстка их только показывает.

```
projects.json   кейсы: главная, /work, страница кейса
lab.json        вертикальные ролики: /lab
```

Править их можно четырьмя способами, и все равноправны:

1. **Админка на сайте** — `/admin`, подключённая к GitHub. Правки живут
   в браузере, пока не нажато «Сохранить»; кнопка делает один коммит в
   репозиторий (json + перетащенные постеры), и workflow выкладывает сайт
   примерно за минуту. Компьютер с проектом для этого не нужен.
2. **Админка локально** — `admin.html` при запущенном `tools/dev-server.py`.
   «Сохранить» пишет файл на диск, дальше обычный коммит и пуш.
3. **Админка без подключения** — «Сохранить» отдаёт готовый json
   скачиванием, его надо положить сюда руками.
4. **Руками** — это обычный json, и ничто не мешает открыть его в
   редакторе.

### Доступ к админке на сайте

Каждый, кто правит сайт, выпускает себе свой токен — общего пароля нет:

1. Владелец репозитория добавляет человека в Collaborators (Settings →
   Collaborators) — или правит сам.
2. Человек открывает
   [github.com/settings/personal-access-tokens/new](https://github.com/settings/personal-access-tokens/new):
   Fine-grained → Resource owner — владелец репозитория → Only select
   repositories → этот репозиторий → Permissions:
   **Contents: Read and write**, **Actions: Read-only** (второе — чтобы
   панель показывала, что сайт обновился).
3. На `/admin` → «Подключить GitHub» → репозиторий, ветка `main`, токен.

Токен хранится только в localStorage этого браузера и отправляется
только на api.github.com. Забрать доступ — удалить токен на GitHub или
убрать человека из Collaborators.

Видео в репозиторий не кладутся: ролики живут в Selectel, в админку
вставляется ссылка. Картинки до 20 МБ панель коммитит сама.

### Сайт для клиента

Та же связка, но всё на клиенте: репозиторий на его GitHub, бакет в его
Selectel, ключи бакета — в секретах его репозитория
(`SELECTEL_S3_ACCESS_KEY`, `SELECTEL_S3_SECRET_KEY`, переменная
`SELECTEL_BUCKET`). В `admin.html` поменять репозиторий по умолчанию в
окне подключения. Ни сервера, ни аккаунта, завязанного на разработчика.

---

## Запуск

```bash
python tools/dev-server.py
```

Сайт — `http://127.0.0.1:8777/`, админка — `/admin.html`.

Открывать `index.html` двойным кликом нельзя: страница читает эти файлы
через `fetch`, а с `file://` браузер запрещает читать даже соседний файл.

## projects.json

```jsonc
{
  "updated": "2026-09-22",
  "branches": { "web": "Web", "branding": "Branding", "motion": "3D & Motion" },
  "projects": [ … ]
}
```

| Поле | Тип | Что значит |
|---|---|---|
| `slug` | строка | Латиница и дефисы. Уходит в адрес `case.html?p=<slug>` — после публикации не меняется. |
| `title` | строка | Название на сайте. Сайт только на английском, русские названия транслитерируем. |
| `titleRu` | строка | Для себя, на сайт не выводится. |
| `client` | строка | Заказчик. |
| `year` | число или `null` | **`null` значит «год не подтверждён»**, и тогда сайт его просто не печатает. Правдоподобная дата хуже пустого места. |
| `branch` | `web` · `branding` · `motion` | Ветка. Ею фильтруется `/work`, на неё ведут ссылки из секции Expertise. |
| `kicker` | строка | Строка под названием: что именно делал. Раскрывается на ховере в сетке главной. |
| `role` | строка или `null` | Честно: арт-дирекция или исполнение. |
| `summary` | строка или `null` | Абзац под заголовком кейса. |
| `capabilities` | массив строк | Объём работ. Печатается через `·`. |
| `cover` | путь или `null` | `assets/work/<slug>-cover.webp`. **Пока файла нет — `null`**: путь без файла даёт 404 на каждой загрузке. Сейчас на сайт не выводится: карточки текстовые, заглушек и графики вместо обложки нет. |
| `logo` | путь или `null` | Знак клиента из `assets/logos`. Красится `currentColor` через маску. |
| `color` | `#RRGGBB` или `null` | Цвет бренда. Если задан — знак встаёт по центру ячейки в четверть её ширины, а на ховере под курсором появляется пятно этого цвета. Пусто — обычная карточка со знаком в подписи. |
| `link`, `linkLabel` | строка или `null` | Живой сайт проекта и подпись кнопки. |
| `featured` | булево | Выносить в сетку главной. **Мест ровно шесть.** |
| `published` | булево | `false` — черновик: лежит в файле, но на сайт не попадает. |
| `status` | `done` · `in-progress` | Служебное, на сайт не выводится. |
| `body` | массив строк | Абзацы кейса. Пустой массив — кейс покажет честную заглушку «текста пока нет». |
| `todo` | массив строк | Что осталось заполнить. На сайт не выводится, видно в админке. |
| `media` | массив | Галерея кейса: `{ "src", "poster"?, "caption"? }`. `src` — путь от `mediaBase` (корень файла) или полный адрес. `.mp4`/`.webm` — видео без звука по кругу. Файл, который не загрузился, на странице просто не показывается. |

`mediaBase` в корне файла — адрес папки в Selectel (`website 3.0/`). Сами
файлы готовятся в `02 Сайт/selectel-upload/` и заливаются туда той же
структурой: `work/<slug>/<файл>`.

## lab.json

```jsonc
{
  "updated": "2026-09-22",
  "intro": "…",                    // подзаголовок раздела
  "instagram": "https://…",        // карточка в конце ленты
  "items": [ … ]
}
```

| Поле | Тип | Что значит |
|---|---|---|
| `slug` | строка | Латиница и дефисы. |
| `title` | строка | Название работы. |
| `date` | `YYYY-MM-DD` или `null` | Печатается как `2026 · March`. |
| `tech` | массив строк | Houdini, Karma XPU, TouchDesigner… |
| `series` | строка или `null` | Например `Mardini 2026 — day 17`. |
| `video` | урл | **Вертикаль 9:16, без звука.** Файл — в Selectel, не в репозитории. |
| `poster` | путь | `assets/lab/<slug>-poster.webp`. Кадр, который стоит в ленте до запуска ролика. Без видео и постера в ленте пустая рамка с номером. |
| `description` | строка | 1–3 предложения: что исследовал и зачем. |
| `published` | булево | `false` — не показывать. |
| `todo` | массив строк | Служебное. |

## Почему так

**Порядок в массиве — это порядок на сайте.** Никакой сортировки по дате
нет: последовательность кейсов — решение, а не следствие календаря. В
админке порядок правится стрелками.

**Пустое поле честнее выдуманного.** Годы и роли по части CG-кейсов в
`03 Клиенты/*/keys.md` до сих пор с TODO. Пока они не подтверждены, в
`year` стоит `null`, и на сайте года просто нет.

**Черновики лежат рядом с опубликованным.** `Форма Будущего`,
`Tempus Watch`, `Женя` и сайт про страхование уже заведены с
`published: false`: данные копятся по ходу работы, а страница
показывает только готовое.
